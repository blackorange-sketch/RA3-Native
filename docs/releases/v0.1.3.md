### What's new

- **Unit and building tooltips** next to the build menu now move and grow together with the enlarged HUD (title, cost, build time and description stay in their box).
- **60 FPS option removed** from the launcher: the game's engine ties its logic and effects to the frame rate, and the phone cannot hold 60 fps in battles anyway. The game runs at a steady 30 fps, as on PC.
- **Log file off by default** in releases, so it costs no CPU time or storage. Turn it on in the launcher when you report a bug (nightly builds keep it on).
- Diagnostics added during testing are now only active with `/sdcard/ra3_verbose`.

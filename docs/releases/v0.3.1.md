### What's new

- **Mods (experimental):** put a mod in a `Mods` folder inside the game folder, one folder per mod as on PC (for example `RA3/Mods/MyMod/MyMod_1.0.skudef` next to the mod's `.big` files), choose it under **Mod** in the launcher and tap **Play**. A mod installed on a PC can be copied from `Documents/Red Alert 3/Mods`. Tried so far with *Armor Rush 3.300* and *Red Alert 3 Advanced 1.2*, in both apps (mods made for 1.12 also start in RA3 Native Steam). See [Mods](https://github.com/blackorange-sketch/RA3-Native#mods-experimental) in the README.
  - The interface language comes from the mod when it has its own texts.
  - Large mods can run slower than the original game: *Armor Rush* needs about three times the processor time per frame in a battle.
  - Steam Workshop items are not listed yet; a Workshop mod can be copied into `Mods`.

### Fixes

- **Other builds of the game file can be started:** a `ra3_1.12.game` (or `ra3_1.13.game`) with another checksum - another edition, language or a modified copy - was refused since v0.2.6. The launcher now shows **UNKNOWN GAME BUILD** in yellow and **Play** stays available; if such a copy crashes, please open an issue with the log file.

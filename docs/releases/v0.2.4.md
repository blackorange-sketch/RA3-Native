### What's new

- **Faster rendering:** effects and their constants are prepared only when something changed, and the render thread makes thousands fewer GPU driver calls per frame (about a quarter less render thread time on a Snapdragon 8 Gen 2). Weaker phones should feel it most.
- **Weak chips with two fast cores** (Helio G85 / G88 / G99 and similar): the drawing thread now really runs on the fast cores.
- **Fast shaders:** explosions, smoke and other particles keep full precision, so they are no longer cut off along straight lines.

### Fixes

- Health bars and windows no longer jump aside when a unit stands next to the right panel (HUD size above 100%).
- Tooltips of the build menu are no longer split in wide screen mode with an enlarged HUD.
- The special abilities window is no longer affected by the HUD scaling.
- A rare crash right after start ("critical section table full").

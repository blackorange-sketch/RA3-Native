### Performance

- **The GPU does about a quarter less work per frame** in battles (measured at 1080p, Ultra, Snapdragon 8 Gen 2: 23 → about 17 ms of GPU time a frame), so the phone runs cooler at the same 30 fps:
  - the bloom's bright-pass, a quarter of the whole frame on Adreno, now reads a half-size copy of the scene (looks the same);
  - depth and stencil buffers that are not needed after the frame are no longer written out to memory.
- **Game code calls are cheaper:** the recompiler now works out which processor registers each game function really reads and changes, and a call hands over only those (about 60% fewer register copies per call).
- **Lighter render thread:** only the graphics state that actually changed is sent to the driver, and merged draws no longer make the next draw set up every vertex attribute again (about a fifth less driver time per draw).

### Fixes

- **Long battles:** the game asked for render-target surfaces and vertex declarations every frame, and each request made a new object that was never freed - over a million in a 25-minute battle, with memory growing and object lookups getting slower late in the game. Each surface and declaration now exists once.

### Controls and interface

- **Number pad buttons** on the keyboard page (N0-N9, N+, N-): the game's camera keys.
- **Camera rotation** speed option in the launcher: how fast a two-finger drag turns the camera.
- **Enlarged HUD:** tooltips of the right column, the buttons under the minimap and the command bar grow with the HUD, including their requirement lines and icons; the right column grows back to full size after a build menu closes.

### For testers

- `/sdcard/ra3_prof` now also logs GPU time per render pass and, every 30 s, a list of one frame's passes.

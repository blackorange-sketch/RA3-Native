### What's new

- **Less heat and battery drain.** Threads that kept CPU cores busy while waiting are now put to sleep: the render thread no longer spins between frames, a Windows event wakes only the threads waiting for it, and the game's job workers poll their queue far less often. In testing the game uses about a fifth less CPU in total.
- **Faster game logic.** The recompiled game code keeps the guest memory base in a register instead of reloading it after every memory write; shader-effect parameters are evaluated only when they change. Big battles hold a higher frame rate.
- **The game no longer keeps running after it is closed.** Closing it from the recent apps list now ends the process (before, the game's threads could keep using the CPU in the background for hours), and the in-game Exit button closes the app right away.
- **Enlarged HUD fixes:** the fourth and later special power buttons scale with the rest of the column, and tooltips above the unit panel's command bar keep their text inside the box.
- README: minimap controls (tap or drag moves the camera, long press sends the selected units).

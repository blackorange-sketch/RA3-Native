### What's new

- **Faster game code.** Virtual calls and function pointers in the recompiled game now jump straight to their target from each call site instead of going through a shared dispatcher. The game's simulation thread uses about half the CPU it did before, and big battles have more headroom.
- **No more hang when saving.** Saving a game (and other moments with lots of varied calls) no longer freezes for a while.
- **Lighter Direct3D layer.** Direct3D objects are found without table lookups, effect textures are resolved once per binding, and tiny game functions are inlined at their call sites.
- More diagnostics in the log for performance work (per-thread CPU use, CPU time per frame).

### What's new

- **Steam version support:** the Steam release of Red Alert 3 (`ra3_1.13.game`, also the Ultimate Collection on Steam) now runs in its own app, **RA3 Native Steam** (`ra3-native-steam-v0.2.6.apk`). It needs no Steam client and no internet connection: a stand-in for Steam answers the game's start-up checks. Wide screen, graphics settings, HUD scaling and draw merging work as in the retail version.
- **Two apps:** **RA3 Native** (`ra3-native-v0.2.6.apk`) for the retail / EA app game (1.12) and **RA3 Native Steam** for Steam. They install side by side with separate settings and saves; each APK holds only its own game code. See [Which app](https://github.com/blackorange-sketch/RA3-Native#which-app-ra3-native-or-ra3-native-steam) in the README.
- The Steam app writes its log to `/sdcard/ra3_native_steam.log`.

### Fixes

- The launcher names the game file it looks for and reports game builds it cannot run (**UNSUPPORTED GAME BUILD** with the file's SHA-256) instead of crashing on start.

Nothing changes in play for the retail version (1.12).

### What's new

- **Better support for Mali and PowerVR GPUs.** These GPUs cannot read the game's DXT textures. They are now converted to ETC2 on the first load and kept in a cache (up to 1.5 GB), so later starts load them directly. Textures stay at full resolution and use a quarter to half of the memory of the previous decoded textures. The first start of each map takes noticeably longer while the cache fills.
- **New launcher option: Fast shaders.** Pixel shaders run at lower precision: faster on Mali and weaker GPUs, with occasional small visual differences. Off by default.
- For testing on other phones: `/sdcard/ra3_nos3tc` forces the Mali texture path, `/sdcard/ra3_noetc` turns the ETC2 conversion off.

Reports from Mali devices (phone model, how it runs, the log file) are very welcome in the issues.

### What's new

- **Less CPU overhead.** The runtime layer between the game and Android was profiled and trimmed: lighter locks, far fewer thread wake-ups, native thread-local storage, faster shader-effect parameter handling. More of the phone's CPU time now goes to the game itself, which helps in big battles.
- **Tooltips of the lower build-menu rows** grow together with the enlarged HUD (the text no longer spills out of its box).
- **Android 10 or newer is now required** (64-bit). Older versions could not use the faster thread-local storage, and phones on Android 8–9 are too weak for the game anyway.
- **Release notes list the APK size and SHA-256.** If the installer says the file is invalid, the download was incomplete: download it again and compare.
